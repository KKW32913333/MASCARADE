# LARVA（ラルファ）― 仮面領の一夜

古典ラテン語で「仮面・亡霊」を意味した語 "larva"（英語 larva の語源。変身前の仮の姿、の比喩）から名付けたオリジナルの心理戦カードゲームです。XENO（中田敦彦氏考案、ラブレターがベースの商業カードゲーム）から「手札1枚・ドロー＆ディスカードで効果発動・心理戦」という**仕組み**だけを参考にし、キャラクター・世界観・カード効果の組み合わせ・ゲーム名はすべて独自に設計しています。

- 舞台：正体を隠したまま王位継承の駆け引きが行われる「仮面領」の一夜限りの舞踏会
- 手札＝「今夜だけ被っている仮面」というメタファー
- 脱落＝「正体を見破られ、舞踏会から退場させられる」

## 今回の更新内容（v3）

1. **PWA化**：`manifest.json` と `sw.js`（Service Worker）を追加し、ホーム画面への追加・オフライン起動に対応しました。`mask-game.js` の末尾で `navigator.serviceWorker.register('./sw.js')` を呼び出しています。アイコンはご提供いただいたロゴ画像（マスク＋トランプ＋「LARVA／ラルウァ」ロゴタイプ）から `icon-192.png` / `icon-512.png`（そのままリサイズ） / `icon-512-maskable.png`（安全マージンを持たせて中央配置）を生成しています。
   - **注意**：Service WorkerはHTTPS、または `localhost` でのみ動作します（`file://` で直接開いた場合は登録がスキップされ、通常のWebページとして動作します）。GitHub Pagesなどにデプロイすれば有効になります。
   - ファイルを更新した際は `sw.js` 内の `CACHE_NAME`（現在 `larva-cache-v1`）を必ず1つ上げてください。上げ忘れるとブラウザが古いキャッシュを返し続けます（Lis Noirでの教訓を踏襲）。
2. **アニメーション・演出を大幅強化**：
   - タイトル画面の段階的フェードイン、金の分割線のシマー演出
   - 背景に漂うパーティクルと、揺らめくキャンドルの光暈（`prefers-reduced-motion` 対応）
   - 手札カードの「呼吸するような光」演出（自分の番の選択待ち時）とホバー時のチルト
   - カードを選ぶと、選んだカードが捨て札置き場へ飛んでいくフライトアニメーション
   - 相手（CPU）が考え中は、手札の背面がゆっくり明滅
   - ターン開始時に「あなたの番／仮面卿の番」のバナーがふわっと表示
   - 脱落時、そのプレイヤーのゾーンが紅く発光してシェイクする演出、退場タグのスタンプ演出
   - 加護中（貴婦人の効果）はシールドアイコンが脈打つ演出
   - 占い師・黒騎士などのモーダルで公開されるカードにフリップイン演出
   - 決着時、勝敗に応じた色のパーティクルが弾ける演出、結果カードの段階的リビール
   - ボタンにシャインスイープとクリック時のリップル効果
   - 山札を3枚重ねのスタック表現に変更し、ゆったり浮遊するアニメーションを追加

5. **LARVAの黄金律を実装**：カード効果が発動するのは**自分の番に自分でその仮面を場に出した時のみ**。以下の通り、他人の効果で捨てさせられた場合や、山札切れによる最後の公開（オープン）では効果が発動しないようにロジックを見直しました。
   - 「毒見役」で強制的に捨てさせられたカードの効果（「仮面の主催者」の即脱落を含む）は発動しません。
   - 「楽団員」の相互公開、「黒騎士」の対決による公開でも、それだけでは脱落しません（黒騎士は純粋に数字の大小のみで決着します）。
   - 山札切れによる最終比較（オープン）でも、公開そのものによる脱落は発生しません。
   - 「仮面の主催者」が脱落するのは、**自分の番に自分の意思でこの仮面を場に出した時**のみです。

## アーキテクチャのポイント（Lis Noirの型を踏襲）

- `CARD_DEFS` にカード1枚＝1オブジェクトで定義。効果は `effect` 種別（`guessRank` / `mutualReveal` / `peekHand` / `protectSelf` / `peekDeckTop` / `swapHand` / `forceRedraw` / `compareHand` / `none`）で分岐し、`Game.eff〇〇()` という汎用関数群で処理しています。
- ゲーム状態は `Game.state` に集約（`deck` / `players` / `turnIndex` / `phase` / `log` など）。
- 画面は `UI.render()` で対象エリアをまるごと再描画する方式（Lis Noirと同じ）。
- カードは画像全面表示＋レアリティ別の縁の輝き（CSSの `box-shadow`）で表現しています。画像そのものに額縁・数字・名前が描き込まれているため、テキストのオーバーレイは行っていません。

## テスト方法

`mask-game.js` には `window.__TEST_FORCE_CPU` フラグと `window.__masqueTestHooks`（`Game`/`CPU`/`UI`/`CARD_DEFS`を公開）を用意しています。jsdomから `window.__TEST_FORCE_CPU = true` を立てた状態で `Game.newGame()` を呼ぶと、両プレイヤーがCPUとして自動進行し、通常より短い待ち時間で最後まで自動再生します。本改修でも40戦連続の自動対戦を実施し、クラッシュなし・脱落決着／山札切れ決着／全員脱落による引き分けの3パターンすべてに到達することを確認済みです。
